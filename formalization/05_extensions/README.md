# 05. Estensioni e Ricerca Futura

Questa cartella raccoglie le estensioni modulari alla formalizzazione base a 3 livelli.

---

## Moduli Pianificati / Proposti

1. **`multi_agent_protocols.md`**: Formalizzazione del passaggio di messaggi, delega tipizzata e topologie di orchestratori multipli ($\Omega_1 \to \Omega_2$).
2. **`convergence_heuristics.md`**: Dimostrazioni di convergenza per $\Phi_{intro}$ e definizione di soglie/limiti superiori al passo $k$ ($k_{max}$) con fallback deterministico.
3. **`memory_algebra.md`**: Definizione formale degli operatori algebrici di compattazione dello stato e riassunto ad intervallo ($S_t \oplus \dots$).
4. **`safety_invariants.md`**: Proprietà di sicurezza formale verificate a tempo di compilazione ed esecuzione (capability verification, isolamento da prompt injection).
